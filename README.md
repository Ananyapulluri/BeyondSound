# BeyondSound 
## 🌐 Live Demo
👉 [beyond-sound.vercel.app](https://beyond-sound.vercel.app)

A web-based coding education platform designed for the deaf and 
hearing-impaired community — delivering programming tutorials 
through native sign language instructors.

## About
BeyondSound makes programming education accessible by providing 
video-based coding courses taught in sign language (ASL). 
The platform bridges the gap between tech education and the 
deaf community.

## Features
- Video-based coding lessons taught in sign language
- Course catalog with beginner to intermediate levels
- Community section for peer interaction
- Exercise/practice module for hands-on learning
- User authentication (sign up / login)
- Fully responsive design

## Courses Available
- Introduction to Python (Beginner)
- Web Development Essentials (HTML, CSS, JavaScript)
- Data Structures & Algorithms (Intermediate)

## Tech Stack
- React + TypeScript
- Vite (build tool)
- Tailwind CSS (styling)
- shadcn/ui (component library)
- React Router (navigation)
- React Query (data fetching)

## Run Locally
npm install
npm run dev

## Purpose
Built to make coding education inclusive and accessible 
for the deaf and hearing-impaired community.
